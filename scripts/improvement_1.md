# Improvement 1: GRPO Collapse Prevention

This change makes the GRPO run more conservative to reduce collapse risk while preserving the full configured training duration. The policy update is smaller with `LEARNING_RATE = 1e-6`, policy drift is more tightly controlled with `BETA = 0.15`, and group-relative advantages should be less noisy with `NUM_GENERATIONS = 4`. Rollouts are also less random with `TEMPERATURE = 0.7` and `TOP_P = 0.95`. Checkpoints continue to be saved every 500 steps for eval-based checkpoint selection, and retention is increased with `MAX_TO_KEEP = 8` so early checkpoints remain available. Reward shaping is softened so format rewards guide valid structure without large negative penalties, and a new short-output penalty directly discourages empty or collapsed completions.
