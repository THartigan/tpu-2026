# Improvement Data 1: Dataset Scaling & MetaMathQA Integration

This change integrates the **MetaMathQA** dataset as an additional training source to solve data starvation during 5-hour TPU training runs. The default GSM8K dataset contains only 7,473 examples, which the model exhausts early in the 5-hour window, leaving valuable TPU compute time unutilized. While repeating epochs would keep the TPU active, it risks overfitting the model to specific prompt formats. MetaMathQA contains 395,000+ augmented math word problems generated from different perspectives, providing a massive, diverse stream of training data. We added a `"metamath"` choice to the CLI `--source` arguments in `train.py` and `evaluate.py` to retrieve MetaMathQA from the Hugging Face Hub, filtering for GSM8K-style `####` delimiters. To prevent evaluation float-casting errors caused by MetaMathQA's trailing `"The answer is: X"` lines, we updated `extract_hash_answer` in `data.py` to keep only the first line of text after the delimiter. We verified the pipeline's correctness through `test_metamath.py`, confirming clean numeric parsing of actual MetaMathQA queries and responses.
